# Turtle Bot Visualizer

TurtleBot Visualizer brings robot simulation and teleoperation to the browser. It spins up a Gazebo environment on AWS EC2, allowing users to take manual control, navigate the world, and observe the LiDAR SLAM system build out real-time point clouds and occupancy grids as the TurtleBot explores unfamiliar terrain.
